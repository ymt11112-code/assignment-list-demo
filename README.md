# 作業清點小幫手 - 線上預覽 Demo

這是「作業清點小幫手」的**靜態預覽頁**，讓你在建立自己的正式版本之前，先摸一下操作介面。

👉 **[點我開啟預覽](https://ymt11112-code.github.io/homework-tracker-demo/)**

## 這個 Demo 能做什麼 / 不能做什麼

- ✅ 頁面一打開就會看到示範學生名冊（8 位學生、分兩組）與一項模擬作業，狀態按鈕、批次修改、依組別檢視等操作都可以直接試玩
- ✅ 資料只存在你目前這個瀏覽器的 `localStorage`
- ❌ 不會雲端同步、不會備份到任何 Google Sheet（純靜態頁面，沒有後端）
- ❌ 積分、觸發器自動加分等需要 Google Apps Script 的功能不會作用

## 想要正式使用（含雲端同步）？

點頁面最上方的「🚀 建立我的專屬副本，開始正式使用」，或直接在正式工具的首頁按「立即開始使用」，把範本 Google Sheet 建立副本到你自己的雲端硬碟並部署，即可擁有一份完全屬於你自己、有雲端備份功能的版本。

---

本 repo 只放預覽用的靜態頁面，不含任何真實班級或學生資料。
