🚀 第一次設定與部署

  1. 建立試算表副本

    點上方按鈕，確認將範本複製到您自己的 Google 雲端硬碟。

  2. 開啟 Apps Script

    在新副本中點選「擴充功能」→「Apps Script」。程式碼已隨範本複製，不需要自己貼上。

  3. 新增網頁應用程式部署

    按右上角「部署」→「新增部署作業」，點齒輪並選「網頁應用程式」。

  4. 設定執行與存取權限

    「執行身分」選「我」；「誰可以存取」依學校帳號允許的選項，選擇要使用的範圍。

  5. 授權並保存專屬網址

    按「部署」後完成 Google 授權，複製結尾為 /exec 的網址。以後請從這個網址開啟真實可用的作業清點系統。

💡 GitHub 這一頁只提供範本與說明；真正的作業資料請從您自己部署的 /exec 網址使用。

⏰ 選用：啟用準時／訂正自動加分

觸發條件不會隨試算表副本複製。只有需要自動加分的使用者，才需要完成以下設定。

  1. 儲存積分設定

    先在自己的 /exec 網頁開啟「個人積分」，設定準時與訂正時間，然後按「儲存設定」。

  2. 執行建立觸發器函式

    回到 Apps Script 編輯器，在上方函式選單選擇 setupPointAutoAwardTriggersManually，按「執行」並完成授權。每份副本只需執行一次。

  3. 確認觸發條件

    到 Apps Script 左側「觸發條件」，確認出現 runOnTimeAwardTrigger 與 runCorrectedAwardTrigger。

不啟用觸發器也不影響作業清點、手動加分與其他功能。
